SoldierAssist 6.0 – Hilfe

Wie starte ich S.A.I.?

Installiere Ollama und starte im Terminal:

ollama run llama3.2

Wie starte ich die Website?

Öffne index.html mit Live Server in Visual Studio Code.

Warum laden Karten oder Wetter nicht?

Diese Funktionen benötigen eine Internetverbindung und erreichbare externe Dienste.

Wo liegen meine Daten?

Lokal im Browser. Sichere wichtige Daten regelmäßig.

Offline-Modus

Lokale Funktionen funktionieren bei geöffneter Seite ohne Internet. Eine installierbare PWA ist in dieser Ein-Datei-Version nicht enthalten.
